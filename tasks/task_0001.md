# task_0001: Domain / Settings 基盤

## 状態

設計レビュー待ち

## 目的

施設建物の配置設計に必要なドメイン定義・設定インフラを実装する。後続タスク（マップ生成・AI・ライフサイクル）が依存する基盤層であり、最初に完了させる必要がある。

## 精査後の確定方針

実装時は互換性維持を考慮せず、`docs/design/ground-facility-placement-design.md` の理想設計を優先する。以下の旧方針は採用しない。

- `Facility` に `BuildingOrigin` / `EntrancePosition` / `SetBuildingInfo()` を直接追加する方針。
- `Facility.IsAtEntrance(GridPosition)` を施設利用・入室判定の主 API にする方針。
- `ActorViewData.IsInsideFacility` を施設入室の中心状態として追加する方針。

代わりに、以下を基盤として実装する。

- `Facility` は施設の経済状態・在庫・品質・収容数を持つ Domain Entity に留める。
- `FacilityBuilding` を `FacilityId` に紐付く配置 Value Object として追加する。
- `FacilityInteractionPoint` を入口接触位置・到着半径・向きの Value Object として追加する。
- `FacilityBuildingLayoutCalculator` で入口セル、建物占有セル、Blocked セル、InteractionPoint を一括計算する。
- `ActorPresence` または `ActorViewPresentationState` を導入し、View 表示状態は施設入口座標ではなく Actor の Task / Interaction 状態から導出する。

具体的には以下を実現する。

- 建物の向き（`BuildingFacingDirection`）を Domain に追加する
- `FacilityBuilding` / `FacilityInteractionPoint` / `FacilityBuildingLayoutCalculator` を追加する
- `GroundMap` には構造セルとしての `FacilityEntrance` を保持する。ただし到着・入室判定の主 API にはしない
- `IFacilityBuildingSettingsRepository` と `FacilityBuildingSettingsSO` で施設建物定義を管理できるようにする
- `WorldGameSettingsSO` / `InitialWorldSettings` の旧フィールド削除と Tavern 設定追加
- `GroundMapGenerationSettings` の旧建物オフセットフィールドを削除する
- Actor の表示状態を表す `ActorPresence` / `ActorViewPresentationState` の基盤を追加する

### 変更ファイル

**`Domain/Facility/FacilityBuilding.cs` / `FacilityInteractionPoint.cs`**

`Facility` に建物情報を直接持たせず、施設配置は `FacilityBuilding` と `FacilityInteractionPoint` で表す。

```csharp
public readonly struct FacilityInteractionPoint
{
    public Guid FacilityId { get; }
    public LayerPosition Position { get; }
    public float Radius { get; }
    public BuildingFacingDirection Facing { get; }

    public bool Contains(LayerPosition actorPosition) { ... }
}

public readonly struct FacilityBuilding
{
    public Guid FacilityId { get; }
    public GridPosition Origin { get; }
    public int WidthCells { get; }
    public int DepthCells { get; }
    public BuildingFacingDirection Facing { get; }
    public GridPosition EntranceCell { get; }
    public FacilityInteractionPoint InteractionPoint { get; }
}
```

`FacilityBuildingDefinition` は設定 DTO、`FacilityBuilding` は計算済み配置として扱う。`FacilityBuildingLayoutCalculator` が `FacilityBuildingDefinition` と `MapLayer` から `FacilityBuilding` を生成する。

**`Domain/Map/GroundMap.cs`**

`FacilityEntrance` セルは構造情報として保持する。以下のような入口セルチェックは追加してもよいが、施設利用・入室判定の主 API にはしない。

```csharp
public bool IsAtFacilityEntrance(GridPosition position)
{
    if (!Layer.Contains(position)) return false;
    return GetCell(position).Type == GroundCellType.FacilityEntrance;
}
```

**`Application/World/ActorPresence.cs` / `ActorViewPresentationState.cs`**

`ActorViewData.IsInsideFacility` のような施設固有フラグではなく、Actor 表示状態を表す値を追加する。

```csharp
public readonly struct ActorPresence
{
    public bool IsVisibleOnMap { get; }
    public Guid? InsideFacilityId { get; }
}

public enum ActorViewPresentationState
{
    Visible,
    HiddenInsideFacility,
    HiddenInDungeonTransition,
    HiddenDespawned
}
```
