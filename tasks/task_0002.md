# task_0002: マップ生成・ギルド初期化

## 状態

設計レビュー待ち

## 目的

地上マップ生成処理を施設建物定義から動的に配置するよう変更し、ギルド初期化で Tavern 生成漏れを修正し、各施設エンティティに建物位置情報を設定する。

## 精査後の確定方針

実装時は `facility.SetBuildingInfo()` による Entity への配置情報注入は採用しない。互換性維持は考慮せず、施設の経済状態とマップ配置を分離する。

確定方針:

- `InitializeWorldMapUseCase` は `FacilityBuildingSettingsSO` から `FacilityBuildingDefinition` を読み、`FacilityBuildingLayoutCalculator` で建物セル・入口セル・InteractionPoint を計算する。
- `GroundMap` には `Building` / `FacilityEntrance` のセルを配置する。
- `InitializeGameWorldOrchestrator` は Inn / Tavern / GeneralStore / EquipmentShop の `Facility` を生成する。
- 施設生成後、`Facility` に配置情報を書き込まず、`FacilityCatalog` または `FacilityBuildingRegistry` に `FacilityId -> FacilityBuilding` を登録する。
- AI / Navigation / Interaction は `FacilityCatalog` から `FacilityBuilding.InteractionPoint` を参照する。

具体的には以下を実現する。

- `InitializeWorldMapUseCase` を `IFacilityBuildingSettingsRepository` のループ処理に変更し、`BuildingFacingDirection` から入口タイルを計算・配置する
- `InitializeGameWorldOrchestrator.CreateInitialGuild()` に Tavern 生成を追加する（既存バグ修正）
- 各施設生成後に `FacilityCatalog` / `FacilityBuildingRegistry` へ計算済み `FacilityBuilding` を登録する

- `[P9] ProductLifetimeScope へのサービス登録` — UseCase への依存注入確認

## 設計

### InitializeWorldMapUseCase の変更

**変更前（現行）**: 4 箇所のハードコードされた `FillRectangle` 呼び出しで建物を配置している。

**変更後**: `IFacilityBuildingSettingsRepository` を DI で受け取り、定義を for ループで処理する。

```csharp
// コンストラクタに追加
readonly IFacilityBuildingSettingsRepository facilityBuildingSettingsRepository;

// Execute() 内の建物配置部分を以下に変更
foreach (var def in facilityBuildingSettingsRepository.GetDefinitions())
{
    // 建物全体を Building / Blocked で塗る
    FillRectangle(cells, layer, def.OriginX, def.OriginZ, def.SizeCells, def.SizeCells,
        GroundCellType.Building, MapCellBlockType.Blocked);

    // Facing から入口ローカル座標を計算
    var (localX, localZ) = CalculateEntranceLocal(def.SizeCells, def.Facing);
    var entrancePos = new GridPosition(def.OriginX + localX, def.OriginZ + localZ);

    // 入口タイルを FacilityEntrance / Walkable で上書き
    SetCell(cells, layer, entrancePos, GroundCellType.FacilityEntrance, MapCellBlockType.Walkable);
}
```

`CalculateEntranceLocal()` のロジック（`SizeCells` を `s` とする）:

| Facing | localX | localZ |
|--------|--------|--------|
| North  | s / 2  | s - 1  |
| South  | s / 2  | 0      |
| East   | s - 1  | s / 2  |
| West   | 0      | s / 2  |

整数除算で実装する（`s = 3` のとき `s / 2 = 1`）。

旧フィールド（`innerOriginX` 等）への参照が残っている場合はすべて削除する。

### InitializeGameWorldOrchestrator の変更

**バグ修正: Tavern 追加**

`CreateInitialGuild()` に Tavern のインスタンス生成を追加する。`InitialWorldSettings` から `TavernBasePrice`・`TavernCapacity` を参照する（task_0001 で追加済み）。

**FacilityBuilding の登録**

各施設生成直後に `IFacilityBuildingSettingsRepository` から対応する定義を検索し、`FacilityBuildingLayoutCalculator` で計算済み `FacilityBuilding` を作成して `FacilityCatalog` / `FacilityBuildingRegistry` に登録する。

```csharp
// 例: Inn の場合
var innDef = facilityBuildingSettingsRepository.GetDefinitions()
    .First(d => d.FacilityType == FacilityType.Inn);
var innBuilding = facilityBuildingLayoutCalculator.Create(inn.Id, innDef, groundMap.Layer);
facilityBuildingRegistry.Register(innBuilding);
```

全施設（Inn、Tavern、GeneralStore、EquipmentShop）に対して同様に処理する。

入口計算は `InitializeWorldMapUseCase` と重複させない。共通の `FacilityBuildingLayoutCalculator` に集約し、UseCase 間呼び出しは禁止する。
