# Milestone 9 Roadmap — ギルド経営 UI

## ゴール

プレイヤーが実際に宿屋ギルドを「経営する」ことができるようになる。
施設のアップグレード、スタッフの採用・配置、収支の確認という経営判断をゲーム内で行えるようにする。

## 対象範囲

### 施設管理画面

- 施設一覧（Inn / Tavern / GeneralStore / EquipmentShop）の現在状態表示
- 施設レベル・品質・キャパシティの表示
- 施設アップグレードの実行（資金を消費して施設レベルを上げる）

### スタッフ管理

- ギルドスタッフの雇用（ギルドへの応募者リストから採用する）
- スタッフの施設への配置・外し
- スタッフ能力値と施設ポイントへの影響の表示
- スタッフ解雇

### 経済ダッシュボード

- 過去 N 日間の収入・支出グラフ
- 施設別売上の内訳
- `GetInnEconomyReportUseCase` / `GetInnEconomyStatusUseCase` の活用
- 在庫・取引履歴の閲覧

### 価格・品揃え設定

- 宿泊料金・食事料金の調整（簡易スライダー）
- 雑貨屋・装備屋の販売価格倍率設定

## Milestone 10 へ移動する項目

- ゲーム開始フロー（初期設定、施設の初期配置）
- 勝敗条件の定義
- セーブ / ロード
