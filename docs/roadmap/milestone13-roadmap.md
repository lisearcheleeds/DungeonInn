# Milestone 13 Roadmap — バランス調整とリリース準備

## ゴール

ゲームを実際にプレイし続けながら、バランス・パフォーマンス・品質を仕上げる。
リリースビルドを出せる状態にする。

## 対象範囲

### AI・経済バランス調整

- 冒険者の行動 AI パラメータ調整（探索頻度・帰還判断・施設利用頻度）
- モンスターの強さと出現バランスの調整
- ギルド収支バランスの調整（宿泊料・食事代・売買価格）
- 施設レベルアップコストと効果のバランス

### パフォーマンス最適化

- フレームレートプロファイリングとホットパスの改善
- GC Alloc 削減の最終パス
- NavMesh / Chunk Mesh のメモリ使用量最適化
- テクスチャアトラス・マテリアルのバッチング確認

### 品質保証

- 全マイルストーンを通じた統合テスト
- エッジケース（極端な資金枯渇、Actor 大量スポーン）の動作確認
- UI / UX の最終レビュー（誤操作防止、フィードバックの明確さ）
- ローカライズ対応（日本語テキストの最終確認）

### リリースビルド準備

- ビルドパイプラインの整備（Addressables ビルド含む）
- プラットフォーム設定の確認
- クラッシュレポート / ログ収集の設定
- デバッグ機能の本番ビルドからの除外
- バージョン管理・リリースノートの整備

## ゴール達成の定義

- 最初から最後まで一通りプレイして、勝利・敗北どちらの経路も動作することを確認できる
- フレームレートが目標値（60fps）を安定して維持できる
- 致命的なバグ・クラッシュが発生しない
- リリースビルドが正常に起動する
