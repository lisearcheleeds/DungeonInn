# Milestone 9.5 Roadmap - 店舗運営 / 購入 AI / バフ

## ゴール

Milestone 9 で作る冒険者ギルド管理と市場の土台に対して、店舗の商品購入、商品生産、酒屋バフ、新米冒険者装備購入を追加する。

## 対象範囲

### 冒険者の商品購入 AI

冒険者が雑貨屋 / 装備屋の商品を購入できるようにする。

- 雑貨屋の商品購入
- 装備屋の商品購入
- 所持ゴールドと必要性に応じた購入判断
- 購入後の inventory / equipment 更新
- 取引履歴への記録

### 新米冒険者の装備屋 0 ゴールド購入

新米冒険者は Spawn 時に装備を直接付与されない。

代わりに、装備屋が 0 ゴールドで販売する新米用装備を購入する。

- 新米用装備ラインナップ
- 0 ゴールド販売
- Spawn 後の購入導線
- 購入後の自動装備

### 生産機能

雑貨屋 / 装備屋の商品は、将来的に冒険者の納品物を素材として生産する。

例:

- 薬草を消費してポーションを生産する
- 鉄鉱石を消費して剣を生産する

Milestone 9.5 では、固定ラインナップから生産ラインナップへ移行する。

### 酒屋バフ

酒屋利用により、5 分間の攻撃力バフを付与する。

- バフの付与
- バフ残り時間
- 攻撃力補正
- UI 表示
- 期限切れ処理

## 対象外

- スタッフ管理
- GuildStaff
- 価格設定 UI
- 複雑な需要シミュレーション

## 実装タスク案

### Task 1: Adventurer Purchase AI

- 冒険者が商品を必要とする条件を定義する
- 雑貨屋 / 装備屋から購入する UseCase を追加する
- 購入結果を取引履歴に記録する

完了条件:

- [ ] 冒険者が所持ゴールドで購入可能な商品を選べる
- [ ] 購入後に inventory が更新される
- [ ] 装備品購入後に装備できる

### Task 2: Rookie Equipment Purchase

- 新米用装備を装備屋の 0 ゴールド商品として定義する
- 新米冒険者が装備屋から購入する
- 購入後に自動装備する

完了条件:

- [ ] Spawn 時の直接装備付与に戻っていない
- [ ] 新米冒険者が 0 ゴールド商品を購入できる
- [ ] 購入後に装備状態になる

### Task 3: Production Master

- 生産レシピ Master を追加する
- 施設レベルごとの生産可能 item を定義する
- 必要素材、生成 item、生成数を Master 化する

完了条件:

- [ ] 雑貨屋 / 装備屋の生産レシピが Master 管理される
- [ ] 施設レベルによって生産可能 item が変わる

### Task 4: Production UseCase

- 素材を消費して商品を生産する
- 生産された商品を店舗ラインナップ / 在庫に反映する

完了条件:

- [ ] 素材が足りる場合だけ生産できる
- [ ] 生産後に素材が消費される
- [ ] 生産物が販売可能になる

### Task 5: Tavern Attack Buff

- 酒屋利用時に攻撃力バフを付与する
- 5 分間の期限を管理する
- 戦闘計算に攻撃力補正を反映する

完了条件:

- [ ] 酒屋利用でバフが付与される
- [ ] 5 分経過でバフが消える
- [ ] バフ中は攻撃力が増加する
- [ ] UI でバフ状態が確認できる
