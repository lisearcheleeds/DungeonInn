# Milestone 10 Roadmap — ゲームループの完成

## ゴール

「ゲームを始めて、進めて、終わる」という一連の流れを完成させる。
タイトル画面からゲームを開始し、目標を達成または資金ショートで終了するまでの
ループが成立した状態にする。

## 対象範囲

### タイトル画面

- タイトル / トップメニュー実装（New Game / Continue / Quit）
- ゲームロゴ・タイトル演出

### ゲーム開始フロー

- 新規ゲーム開始時の初期設定（ギルド名・難易度など）
- 初期施設配置・スタッフ配置の確認画面
- 簡易チュートリアル（最初の数日間をガイドする）

### 勝敗条件

- **勝利**: 評判レベルが目標に到達する、または資金目標を達成する（仕様は別途確定）
- **敗北**: ギルド資金がゼロを下回り、支払い不能になる
- 勝利 / 敗北時のエンドスクリーン

### セーブ / ロード

- ゲーム進行状態のシリアライズ（Domain / Application の状態を JSON または独自バイナリで保存）
- 自動セーブ（日付切り替わり時）
- タイトル画面からのロード
- セーブスロット管理

### 日付サイクルの可視化

- 朝・昼・夕・夜の時間帯変化を画面演出で表現する
- 施設の営業時間に合わせた UI / HUD の表示切り替え

## Milestone 11 へ移動する項目

- コンテンツ拡充（モンスター種類、装備種類、ダンジョン深層）
- Pet システム
- Faction 勢力管理 UI
