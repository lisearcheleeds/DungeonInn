## GuildStaff / スタッフ管理

### 状態

保留。Milestone 9 / 9.5 では何もしない。

### 保留する理由

GuildStaff は Actor の Behavior 差し替え、スタッフ雇用、施設配置、施設ポイント、給与、AI 勤務判断まで波及する。

Milestone 9 はダンジョン情報、冒険者ギルド管理、市場を ScreenStack window として実装することを優先する。ここで GuildStaff を入れると、UI 実装と Domain / Application の新規ゲームフローが混ざる。

### 将来検討する範囲

- GuildStaffBehavior
- GuildStaffAssignment
- 冒険者のスカウト
- スタッフ雇用、配置、解雇
- スタッフ能力値から施設ポイントへの変換
- スタッフ給与
- GuildStaff 用 AI / 勤務判断
- スタッフが冒険者活動を停止するか、兼任できるかの仕様決定

### 再開条件

- 冒険者ギルド管理と市場の基本 UI が完成している
- 施設アップグレードがスタッフなしで成立している
- スタッフ化した Actor のライフサイクルを仕様として決めている

## 価格設定 UI

### 状態

保留。Milestone 9 / 9.5 では実装しない。

### 保留する理由

価格設定は、宿泊料、食事代、販売価格倍率、買取価格、施設レベル、需要、Actor 所持ゴールド、取引履歴に影響する。

Milestone 9 では MarketOffer と施設アップグレードを Master 管理し、プレイヤーによる価格調整は扱わない。Milestone 9.5 でも購入 AI と生産を優先し、価格編集 UI は扱わない。

### 将来検討する範囲

- 宿泊料の設定
- 食事代の設定
- 買取価格 / 販売価格倍率の設定
- 価格変更による需要や満足度への影響
- PricePolicy との責務分離

### 再開条件

- 現在の経済ダッシュボードで収支の観測ができる
- 価格を変えることで何が変化するべきかの仕様が決まっている
- 価格変更の保存形式と UI 操作単位が決まっている
